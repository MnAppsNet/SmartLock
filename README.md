# SmartLock
Smartlock is a tool developed to let the users encrypt and decrypt data using Windows Hello features. 
This allows the users to protect their data using their face or fingerprints without needing a password every time.

# SmartLock.cs
SmartLock.cs file contains a class with all the functionality of the application and can be incorporated in other windows applications.
Along with SmartLock.cs, Conf.cs is used which holds some configurable information for SmartLock like the return status messages.
